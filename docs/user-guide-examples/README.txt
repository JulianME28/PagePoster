НАВЧАЛЬНІ ПРИКЛАДИ PAGEPOSTER

02-html-project.zip: три готові HTML-сторінки, таблиця зі slug, мовою та GEO. Завантажте ZIP через «Імпорт проєкту». Донорів у прикладі не задано: виберіть власні дозволені сайти перед публікацією.

01-ai-project.csv: один рядок для генерації англійською. Після імпорту підготовка використовує підключений OpenAI API. Адреси example навчальні; замініть їх своїми робочими посиланнями перед реальним використанням.

Для першого знайомства почніть із готового HTML ZIP. Це матеріали для тренування, а не готове замовлення на розміщення.

03-donor-base-template.csv: шаблон бази сайтів для Google Таблиць, не для імпорту сторінок у PagePoster. Збережено схему A–O: домен у B, DR у D, трафік у E, GEO у F, логін і пароль у K/L, другий доступ у N/O. Замініть навчальні домен і доступи своїми перед використанням.
